# うるさい — как выложить и установить

## Самый простой хостинг (2 минуты, бесплатно)
1. Распакуй архив `urusai.zip` — внутри папка с файлами `index.html`, `sw.js`, `manifest.webmanifest` и иконками.
2. Открой https://app.netlify.com/drop и перетащи туда **всю папку**.
3. Netlify даст ссылку вида `https://что-то.netlify.app` — её и отправляй маме.

Подойдёт и любой другой хостинг со статикой по **https** (GitHub Pages, Cloudflare Pages, свой сервер). Для установки на телефон обязателен https (или localhost).

## Установка на телефон
- **Android (Chrome):** открыть ссылку → кнопка «Установить на телефон» в приложении (или ⋮ → «Установить приложение»).
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После установки приложение работает и без интернета (кроме японских шрифтов при самом первом запуске — они сохраняются после первого открытия).

## Где хранится прогресс
Чипси, звёзды, наклейки и знание каждого знака хранятся в памяти браузера на телефоне.
В «Настройках» есть «Резервная копия»: код можно скопировать и вставить на другом устройстве.

## Обновление
Если поменяешь файлы и зальёшь заново на тот же адрес, приложение подхватит новую версию при следующем открытии с интернетом. Прогресс при этом не теряется.
